Welcome to the Web & How HTML Works

Before we write a single line of code, let's understand what actually happens when you visit a website — and where HTML fits into that story.

🎯 Learning Objectives
  • Explain what the internet, a web page, and a browser are, in your own words
  • Describe what HTML stands for and the job it does
  • Understand how a browser turns HTML code into the page you see
  • Set up the two tools you'll use throughout this course

1What Happens When You Visit a Website?

Every time you open a web page — whether it's a game, a school site, or YouTube — the same basic story happens behind the scenes. Your browser (like Chrome, Edge, or Firefox) sends a request across the internet to a server, which is just a powerful computer that stores web pages. The server sends the page's code back to your browser, and your browser reads that code and draws it on your screen in a fraction of a second.

🌐

The Internet

A giant network of connected computers all over the world that can send information to each other.

🖥️

A Server

A computer that stores website files and "serves" them to anyone who asks for them.

The most important thing to know is this: every web page is really just a text file full of code. Your browser's whole job is to read that text file and turn it into the buttons, pictures, and text you interact with. That code is written in a language called HTML — and by the end of today, you'll have written some yourself.

2What Is HTML?

HTML stands for HyperText Markup Language. Let's break that name down, because each part tells you something important:

  • HyperText — text that can link to other text (think of clicking a blue underlined link that jumps you to another page)
  • Markup — HTML "marks up" plain text by wrapping it in tags that tell the browser what each piece of content is (a heading? a paragraph? a picture?)
  • Language — it's a language with its own vocabulary and rules, just like English or Spanish has rules — except this language is for talking to computers

HTML is not a "programming language" that does math or makes decisions — it's a structure language. Think of it like the skeleton of a body: it doesn't make the body move or look pretty, but without it, everything would collapse into a pile. Later courses add CSS (the "skin and clothes") and JavaScript (the "muscles that move things") — but we start with the skeleton, because everything else is built on top of it.

example.html
<h1>Welcome to my page!</h1>
<p>This paragraph is marked up with a tag.</p>
🔒 example.html

Welcome to my page!

This paragraph is marked up with a tag.

Notice the pattern: a tag like <h1> opens, some content sits inside, and a matching </h1> closes it — with a forward slash. Together, an opening tag, its content, and its closing tag are called an element. You'll type this pattern hundreds of times in this course, so it will quickly feel natural.

3How the Browser "Reads" Your Code

A browser reads HTML from top to bottom, the same way you read a book. As it goes, it looks at every tag and decides how to display whatever is inside it. It doesn't care about spacing or indentation the way you might expect — it cares about tags and structure. This is why professional coders still indent their code neatly: it's not for the browser, it's so humans can read it easily.

💡 Good Habit

Even though browsers don't require neat spacing, always indent your code and keep related tags together. Messy code is much harder to fix when something goes wrong — and something always eventually goes wrong!

4Meet Your Toolkit

You only need two things for this entire course:

  • A text editor — this is where you'll type your HTML code. We recommend Visual Studio Code (free), though Notepad or TextEdit also work for now.
  • A web browser — this is where you'll see your code come to life. Chrome, Edge, or Firefox are all great choices.

Important: never write HTML in a program like Microsoft Word. Word adds hidden formatting that breaks your code. Always use a plain text editor.

📚 Key Vocabulary
HTML
HyperText Markup Language — the language used to structure content on the web
Browser
The program (like Chrome) that reads HTML and displays it as a page
Server
A computer that stores and delivers website files
Tag
A keyword wrapped in angle brackets, like <p>, that marks up content
Element
An opening tag, its content, and its closing tag together
Text editor
Software used to write plain-text code, like VS Code
🚀 Challenge

Install and open your text editor (VS Code is recommended). Type this single line exactly as shown:

<h1>I just wrote my first line of HTML!</h1>

Save the file as first-line.html, then find it on your computer and double-click it to open it in your browser. You should see your sentence appear as a big heading. Congratulations — you're officially a web developer!

✅ Recap

The internet connects computers so servers can send web pages to browsers. HTML is the markup language that structures those pages using tags and elements. Browsers read HTML top to bottom and display it visually. You now have the two tools you need: a text editor and a browser. Next lesson, we'll build a complete, properly structured web page.
