Text Formatting, Entities & Comments

Learn how to emphasize important words, insert special characters, and leave yourself helpful notes inside your code.

🎯 Learning Objectives
  • Use <strong> and <em> to add semantic emphasis
  • Insert line breaks and horizontal rules appropriately
  • Use HTML entities to display special characters
  • Write comments that browsers ignore but humans can read

1Bold and Italic — the Right Way

HTML actually gives you two ways to make text bold, and two ways to make it italic. They look the same by default, but they mean different things:

  • <strong> — marks text as important (semantic meaning). Screen readers may say it with extra emphasis.
  • <b> — just makes text bold visually, with no special meaning.
  • <em> — marks text as emphasized, like you'd stress a word when speaking (semantic meaning).
  • <i> — just makes text italic visually, with no special meaning (often used for terms or titles).
💡 Which Should I Use?

Default to <strong> and <em> — they carry meaning for accessibility tools, not just looks. Save <b> and <i> for cases where you truly just want a visual style with no added importance, like a book title.

formatting.html
<p>Never share your <strong>password</strong> with anyone.</p>
<p>I <em>really</em> loved that movie.</p>
🔒 formatting.html

Never share your password with anyone.

I really loved that movie.

2Line Breaks & Horizontal Rules

Sometimes you need a line break within a paragraph (not a whole new paragraph). Use <br> for that. To draw a horizontal divider line between sections, use <hr>. Both are self-closing — they have no separate closing tag because they don't wrap any content.

address.html
<p>123 Maple Street<br>
Springfield, IL 62704</p>
<hr>
⚠️ Don't Overuse <br>

New learners often use several <br> tags in a row to create empty space. Don't — that's a job for CSS spacing later. Use <br> only when a genuine line break belongs inside one piece of content, like an address.

3HTML Entities: Typing Special Characters

Some characters have a special meaning in HTML — like < and >, which the browser normally reads as the start/end of a tag. To display these characters as plain text, you use an entity: a short code starting with & and ending with ;.

< (less than)&lt;
> (greater than)&gt;

A non-breaking space&nbsp;

4Comments: Notes the Browser Ignores

You can leave notes for yourself (or teammates) directly in your code using comments. Browsers skip over anything inside <!-- --> completely — visitors never see it.

comments.html
<!-- TODO: add a photo here later -->
<p>This page is still under construction.</p>
<!-- End of intro section -->
📚 Key Vocabulary
Semantic
Carrying meaning, not just visual style
Entity
A code like &copy; used to display a special character
Self-closing tag
A tag with no separate closing pair, like <br> or <hr>
Comment
A note in code, wrapped in <!-- -->, invisible to visitors
🚀 Challenge

In your hobby.html file from last lesson, add: one sentence using <strong>, one sentence using <em>, a copyright line at the bottom using the &copy; entity (e.g. "&copy; 2026 Your Name"), and a comment marking where your favorite section begins.

✅ Recap

Use <strong> and <em> for meaningful emphasis, <br> and <hr> sparingly for breaks and dividers, entities for special characters, and comments to leave notes browsers won't display. Next lesson: organizing content into lists.
