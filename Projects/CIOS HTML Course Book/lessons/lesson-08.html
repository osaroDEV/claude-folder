Building Tables

When you need to display rows and columns of information — like a schedule or scoreboard — HTML tables are the tool for the job.

🎯 Learning Objectives
  • Build a table using <table>, <tr>, and <td>
  • Add header cells and group rows with thead/tbody
  • Merge cells using colspan and rowspan
  • Know when a table is (and isn't) the right choice

1Table Basics: Rows and Cells

A table is built from three nested tags: <table> wraps everything, <tr> (table row) creates each row, and <td> (table data) creates each cell within a row.

table-basic.html
<table>
  <tr>
    <td>Alex</td>
    <td>92</td>
  </tr>
  <tr>
    <td>Jamie</td>
    <td>87</td>
  </tr>
</table>

2Header Cells & Structure

Use <th> (table header) instead of <td> for cells that label a column or row — browsers automatically bold and center them, and screen readers announce them as headers. Well-organized tables also group content using <thead> (for header rows) and <tbody> (for the data rows).

table-full.html
<table>
  <thead>
    <tr>
      <th>Student</th>
      <th>Score</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>Alex</td>
      <td>92</td>
    </tr>
    <tr>
      <td>Jamie</td>
      <td>87</td>
    </tr>
  </tbody>
</table>

3Merging Cells: colspan & rowspan

Sometimes one cell needs to stretch across multiple columns or rows. Use colspan to merge across columns, and rowspan to merge across rows.

colspan.html
<tr>
  <th colspan="2">Weekly Schedule</th>
</tr>

That single header cell now spans the width of two normal columns beneath it — perfect for a title row above a schedule.

4When (Not) to Use a Table

⚠️ Tables Are for Data, Not Layout

Years ago, web developers misused tables to arrange whole page layouts (menus, sidebars, columns). That's now considered bad practice — tables should only hold genuine tabular data, like a schedule, scoreboard, or price list. Later, you'll learn CSS, which is the correct tool for page layout.

📚 Key Vocabulary
<table>
The container for an entire table
<tr>
Table row — one horizontal line of cells
<td> / <th>
A regular data cell / a header cell
colspan / rowspan
Attributes that merge a cell across columns or rows
🚀 Challenge

Build schedule.html with a table showing your weekly class or activity schedule: a header row with day names, and one row per time slot. Use <thead>, <tbody>, and at least one merged cell with colspan.

✅ Recap

Tables are built from <table>, <tr>, and <td>/<th>, organized with <thead>/<tbody>. colspan and rowspan merge cells. Tables should hold real data, never be used for page layout. Next lesson: collecting information with forms.
