Mini Project Part 1: Planning Your Profile Page

Time to bring everything together. Over the next two lessons, you'll plan and build one complete, polished personal profile page — your final project.

🎯 Learning Objectives
  • Understand the full scope of the final project
  • Plan a page's content and structure before coding
  • Set up a clean, organized project folder
  • Build a semantic HTML skeleton ready to fill in

1What You're Building

Your final project is a personal profile page — think of it as a mini "About Me" website. It must use nearly everything you've learned across this course: headings, paragraphs, lists, links, an image, a table, a form, and semantic layout elements.

SectionMust include
HeaderYour name as an <h1>, plus a short nav menu with jump links to each section
About MeA photo (with alt text and a caption) and 2–3 introductory paragraphs
InterestsA list of your hobbies or interests (nested list encouraged)
Fun FactsA small table comparing things about you (e.g. favorites by category)
ContactA simple form (name, email, message) so a "visitor" could reach you
FooterA copyright line using the &copy; entity

2Planning Your Content

Before writing any code, sketch a quick text outline — exactly like you practiced in Lesson 3. Answer these questions on paper or in a notes file first:

  • What's my page title going to be?
  • What 2–3 sentences describe me in the About section?
  • What 4–5 interests will I list?
  • What 3–4 "fun facts" will go in my table, and what categories?
  • What fields does my contact form need?
💡 Planning Saves Time

Five minutes of planning on paper prevents a confused, half-finished page later. Professional developers almost always sketch or outline before touching code — you're building that habit right now.

3Setting Up Your Project Folder

Create a new folder called my-profile-page. Inside it, create an images subfolder for any pictures you'll use, and your main file, index.html. Keeping images in their own subfolder is standard practice — it keeps projects tidy as they grow.

folder structure
my-profile-page/
  index.html
  images/
    my-photo.jpg

4Building the Skeleton

Now build the empty semantic structure — no real content yet, just the "bones" with comments marking what goes where. This is exactly the skeleton-first approach professionals use.

index.html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>Your Name — Profile</title>
</head>
<body>
  <header>
    <!-- h1 name + nav links go here -->
  </header>

  <main>
    <section id="about">
      <!-- photo + intro paragraphs -->
    </section>

    <section id="interests">
      <!-- interests list -->
    </section>

    <section id="facts">
      <!-- fun facts table -->
    </section>

    <section id="contact">
      <!-- contact form -->
    </section>
  </main>

  <footer>
    <!-- copyright line -->
  </footer>
</body>
</html>
📚 Key Vocabulary
Wireframe / outline
A rough plan of a page's content before coding
Project folder
A dedicated folder holding a project's files, kept organized with subfolders
Skeleton
Empty structural HTML, ready to be filled with real content
🚀 Challenges

Three challenges, each a little tougher than the last. Challenge 1 is the must-do; Challenges 2 and 3 are where you level up.

Challenge 1CorePlan & Build the Skeleton

Write your content plan (the five questions above) in a notes file. Then set up your my-profile-page folder and build the exact skeleton shown above, saved as index.html. Don't fill in real content yet — that's next lesson.

Challenge 2Level UpPaper Wireframe

On a sheet of paper, draw your profile page as a stack of boxes from top to bottom — one box for each section in the table above. Inside each box, write:

  • The semantic tag it will use (header, section, footer…)
  • Its id, if it has one (e.g. id="about")
  • Two or three words about what goes inside

Draw the nav inside your header box and list the links it will have. Take a photo of your sketch and save it as wireframe.jpg in your images folder. Keep it beside you next lesson as your map.

Challenge 3Boss LevelTest-Drive Your Skeleton

Make your empty skeleton actually work before any real content goes in:

  • Inside <header>, add an <h1> with your name and a <nav> with four jump links: #about, #interests, #facts, #contact
  • Give every section a temporary <h2> and a few "Coming soon…" paragraphs, so the page is long enough to scroll
  • Click every nav link. Any link that doesn't jump? Check the spelling of the id and the #
  • Add a comment at the very top of <body> with your name and today's date
  • Final check: are all your file and folder names lowercase with no spaces?
✅ Recap

Your final project is a multi-section personal profile page. Planning your content before coding saves time and confusion. You now have an organized project folder and a semantic skeleton ready to fill in. Next lesson: building and polishing the real thing.
