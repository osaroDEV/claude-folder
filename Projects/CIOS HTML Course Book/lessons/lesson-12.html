Audio, Video & Embedding Content

HTML isn't just text and images — it can play sound, show video, and even embed content from other websites.

🎯 Learning Objectives
  • Embed audio using the <audio> element
  • Embed video using the <video> element
  • Provide multiple file formats with <source>
  • Embed external content using <iframe>

1Adding Audio

The <audio> element plays sound files. Add the controls attribute so visitors get play/pause/volume buttons — without it, there's no visible player at all.

audio.html
<audio src="audio/theme-song.mp3" controls></audio>

2Adding Video

The <video> element works the same way, plus a few extra useful attributes: width/height to size the player, and poster to show a preview image before playback starts.

video.html
<video src="video/intro.mp4" controls width="480" poster="images/preview.jpg"></video>
🔒 video.html
▶️

3Multiple Formats with <source>

Not every browser supports every video/audio file format. Instead of a single src, you can list several <source> options inside the tag — the browser picks the first one it can play.

video-sources.html
<video controls width="480">
  <source src="video/intro.mp4" type="video/mp4">
  <source src="video/intro.webm" type="video/webm">
  Your browser doesn't support video playback.
</video>

The plain text at the end is a fallback message, only shown if the browser can't play any of the listed sources.

4Embedding Other Content with <iframe>

An <iframe> (inline frame) embeds an entire other web page inside yours — commonly used for maps, YouTube videos, or other widgets that provide "embed" code.

iframe.html
<iframe
  src="https://www.youtube.com/embed/dQw4w9WgXcQ"
  width="480"
  height="270"
  title="Sample embedded video">
</iframe>
⚠️ Only Embed Trusted Sites

An iframe loads content from another website directly into yours. Only embed sources you trust (like an official YouTube or Google Maps embed code), and always include a descriptive title attribute so screen reader users know what the embedded frame contains.

📚 Key Vocabulary
controls
Attribute that shows play/pause/volume buttons
poster
A preview image shown before a video plays
<source>
Lists an alternate file format for audio/video
<iframe>
Embeds another web page inside the current one
🚀 Challenges

Three challenges, each a little tougher than the last. Challenge 1 is the must-do; Challenges 2 and 3 are where you level up.

Challenge 1CoreAdd Media to Your Page

Add either an <audio> or <video> element with controls to one of your existing pages (any royalty-free file works). Then embed one <iframe> — for example, an embedded map or video — complete with a descriptive title attribute.

Challenge 2Level UpMovie Trailer Card

Build trailer.html — a "coming soon" card for a film (a real one, or one you invent!). Include:

  • A <video> with controls, a width, and a poster image
  • Two <source> tags inside it — one MP4 and one WebM, each with the correct type value — plus a fallback message
  • The whole video wrapped in a <figure> with a <figcaption> giving the film's title and year
  • A short paragraph below it describing the film

Tip: put the MP4 source first. If you only have an MP4 file, that's fine — the browser plays the first source it can and skips the rest.

Challenge 3Boss LevelMy Favourite Place

Build place.html about a public place you love — a park, a beach, a market, a town you've visited. (Pick a public place, not your home address!) Your page needs:

  • Semantic structure: <header>, <main> with at least two <section>s, and a <footer>
  • An <iframe> map of the place (in Google Maps: Share → Embed a map → copy the code) with a descriptive title
  • An <audio> player of a sound that matches the place (waves, birds, market noise) using a <source> tag and fallback text
  • An ordered list: "Top 3 things to do there"

Experiment: delete the controls attribute from your audio and refresh. What do you see? Put it back, then write a comment explaining what controls does.

✅ Recap

<audio> and <video> embed media with the controls attribute enabling playback UI. Multiple <source> tags offer format fallbacks. <iframe> embeds another page entirely — use only trusted sources and always add a title. Next lesson: attributes and accessibility, in depth.
