Mini Project Part 2: Build & Polish

Your skeleton is ready. Today you'll fill it with real content using everything you've learned, then proofread it like a professional.

🎯 Learning Objectives
  • Fill each section of the skeleton with real content
  • Correctly combine every tag category learned this course
  • Identify and fix common HTML mistakes
  • Review a finished page against a quality checklist

1Filling In Your Content

Open your skeleton from last lesson and replace each comment with real, finished HTML. Work section by section — don't try to do it all at once. After each section, save and refresh your browser to check your progress.

index.html (about section, filled in)
<section id="about">
  <h2>About Me</h2>
  <figure>
    <img src="images/my-photo.jpg" alt="Portrait of me smiling outdoors" width="220" height="220">
    <figcaption>That's me!</figcaption>
  </figure>
  <p>Hi, I'm Amara! I'm 13 years old and I love robotics and drawing.</p>
  <p>I'm learning to code because I want to <em>build my own apps</em> one day.</p>
</section>

2Bringing In Everything You've Learned

Use this checklist to make sure your finished page genuinely covers the whole course:

✔Requirement
☐One <h1>, with a logical heading hierarchy below it
☐At least one properly captioned <figure> + <img> with real alt text
☐An unordered or nested list of interests
☐A table with <thead>/<tbody> showing fun facts
☐A working nav with jump links to each section (id + #)
☐A form with correctly labeled inputs and a required field
☐Semantic layout: header, main, section(s), footer
☐A footer with a &copy; entity and the current year

3Proofreading Your Code

Before calling it finished, check for these classic beginner mistakes:

  • Unclosed tags — every opening tag needs its matching closing tag (except self-closing ones like <img>, <br>, <input>)
  • Mismatched tags — closing tags must close in the reverse order they opened, like nested parentheses
  • Missing quotes — attribute values always need quotes: alt="a dog", not alt=a dog
  • Broken for/id pairs — double-check every label's for attribute exactly matches its input's id
⚠️ One Small Typo Can Break a Page

A missing closing tag or quote mark can make your entire layout collapse unexpectedly. If something looks wrong in the browser, the fix is almost always a small typo — read your code carefully, tag by tag, rather than assuming something complicated went wrong.

4Self (or Peer) Review

Read your finished page out loud from top to bottom, as if you were a visitor seeing it for the first time. Does it make sense? Is anything confusing or missing? If you're taking this course with classmates, swap pages and give each other one thing you liked and one suggestion.

🚀 Challenges

Three challenges, each a little tougher than the last. Challenge 1 is the must-do; Challenges 2 and 3 are where you level up.

Challenge 1CoreFinish Your Profile Page

Complete every section of your profile page. Go through the requirements checklist above and check off each box honestly. Fix any proofreading issues you find before moving to the final lesson.

Challenge 2Level UpBug Hunt

This piece of a profile page has 5 classic mistakes — the same ones from the proofreading list above. Copy it into bug-hunt.html and fix them all.

bug-hunt.html
<section id="interests">
  <h2>My Interests</h3>
  <ul>
    <li>Football</li>
    <li>Drawing <em>comics</li>
    <li><strong>Coding</li></strong>
  </ul>
  <img src="images/football.jpg" alt=Me playing football>
</section>

<section id="contact">
  <label for="your-name">Name</label>
  <input type="text" id="yourname" name="yourname" required>
</section>

Found all five? Now run the same bug hunt on your own profile page, tag by tag.

Challenge 3Boss LevelBonus Section + Two Stars and a Wish

Add a sixth section to your profile page — <section id="favourites"> — that shows off something from Lessons 12–13 your page doesn't use yet:

  • An embedded video or <iframe> (with a descriptive title), or an <audio> player with controls
  • At least one data-* attribute or a class shared by two elements
  • A new link in your nav that jumps to this section — test it!

Then ask a classmate or family member to give you two stars and a wish: two things they like, and one thing to improve. Write their feedback as a comment at the bottom of your file — then make the improvement.
