Forms Part 2: Choices, Buttons & Validation

Beyond text fields, forms can offer checkboxes, choices, dropdowns, and long text — plus ways to stop a form from being submitted incorrectly.

🎯 Learning Objectives
  • Add checkboxes for multiple independent choices
  • Add grouped radio buttons for a single choice
  • Build dropdown menus and multi-line text areas
  • Use the required attribute for basic form validation

1Checkboxes

Use type="checkbox" when someone can pick any number of options — including none, one, or all of them.

checkboxes.html
<input type="checkbox" id="pizza" name="toppings" value="pizza">
<label for="pizza">Pizza</label>

<input type="checkbox" id="tacos" name="toppings" value="tacos">
<label for="tacos">Tacos</label>

2Radio Buttons

Use type="radio" when someone must pick exactly one option from a group. The trick that makes them work as a group is giving every radio button in that group the same name — this tells the browser they're mutually exclusive.

radio.html
<input type="radio" id="small" name="size" value="small">
<label for="small">Small</label>

<input type="radio" id="large" name="size" value="large">
<label for="large">Large</label>
⚠️ Same name, different id

Every radio button in one group shares the same name (so the browser groups them), but each still needs its own unique id (so its label connects to the right one). Mixing this up is the #1 radio button bug.

3Dropdowns & Text Areas

A dropdown menu uses <select> as the container, with each choice as an <option> inside it. For longer, multi-line text (like a comment or message), use <textarea> instead of <input>.

select-textarea.html
<label for="grade">Grade Level</label>
<select id="grade" name="grade">
  <option value="6">Grade 6</option>
  <option value="7">Grade 7</option>
  <option value="8">Grade 8</option>
</select>

<label for="comments">Comments</label>
<textarea id="comments" name="comments" rows="4"></textarea>

4Buttons & Basic Validation

A <button type="submit"> sends the form; type="reset" clears it. To stop a form from submitting until a field is filled in, add the required attribute — no JavaScript needed.

validation.html
<label for="email">Email</label>
<input type="email" id="email" name="email" required>

<button type="submit">Send</button>

Try submitting a form with a required field left empty — the browser blocks it and shows a built-in warning message, automatically.

📚 Key Vocabulary
Checkbox
An input allowing multiple independent selections
Radio button
An input allowing one choice from a grouped set
select / option
Elements that create a dropdown menu of choices
textarea
A multi-line text input field
required
An attribute that blocks submission until a field is filled
🚀 Challenges

Three challenges, each a little tougher than the last. Challenge 1 is the must-do; Challenges 2 and 3 are where you level up.

Challenge 1CoreThe Feedback Form

Build feedback.html: a form with a radio group ("How was your day?" — Great / Okay / Rough), at least two checkboxes ("What did you enjoy?"), a dropdown, a textarea for comments, a required email field, and a submit button.

Challenge 2Level UpPizza Palace Order Form

Build order.html for a pretend pizza shop. Your form must include:

  • A radio group for size: Small, Medium, Large (one shared name, three different ids)
  • At least four topping checkboxes
  • A dropdown to choose Pickup or Delivery
  • A textarea for "Special instructions" with rows="3"
  • A required name field
  • A submit button and a reset button

Test it three ways: try picking two sizes (only one should stay selected), try submitting with no name (the browser should stop you), then fill everything in and click Reset (it should all clear).

Challenge 3Boss LevelFix & Upgrade the Survey

Someone built this club survey in a hurry and it's broken. Copy it into survey.html.

survey.html
<form>
  <p>Favourite subject?</p>
  <input type="radio" id="maths" name="subject1" value="maths">
  <label for="maths">Maths</label>
  <input type="radio" id="maths" name="subject2" value="science">
  <label for="maths">Science</label>

  <p>Which clubs do you attend?</p>
  <input type="radio" id="chess" name="clubs" value="chess">
  <label for="chess">Chess</label>
  <input type="radio" id="drama" name="clubs" value="drama">
  <label for="drama">Drama</label>

  <label for="mail">Email</label>
  <input type="email" id="mail" name="mail">
  <button>Send</button>
</form>

Fix it so that: (1) the subject radio buttons work as one group, (2) each subject has its own unique id and a label that connects to it, (3) visitors can pick more than one club (hint: wrong input type!), and (4) the email can't be left empty.

Then upgrade it: add a third subject, a "How did you hear about our clubs?" dropdown, a textarea for suggestions, a Reset button, and give the Send button an explicit type="submit".

✅ Recap

Checkboxes allow multiple picks; radio buttons (grouped by matching name) allow exactly one. select/option builds dropdowns, textarea holds multi-line text, and required gives free built-in validation. Next lesson: organizing pages with div, span, and semantic HTML.
