Adding Images

Pictures make pages come alive. Today you'll learn how to add images correctly — including a step every beginner forgets.

🎯 Learning Objectives
  • Insert images using the <img> tag
  • Explain why alt text is required, not optional
  • Size images properly using width and height
  • Add captions with <figure> and <figcaption>

1The <img> Tag

Images use the self-closing <img> tag. It needs a src (source) attribute pointing to the image file — either a file in your own project or a full web address.

image.html
<img src="images/mountain.jpg" alt="Snow-capped mountain at sunrise">

2Alt Text: Not Optional

The alt attribute describes the image in words. It does two important jobs:

  • Screen readers read it aloud, so blind or low-vision visitors know what the image shows
  • If the image fails to load (a typo in the file name, a slow connection), the browser shows the alt text instead — so nobody sees a broken, meaningless icon
⚠️ Write Real Descriptions

Avoid vague alt text like alt="image" or alt="pic1". Describe what's actually shown: alt="A golden retriever catching a frisbee in a park". If an image is purely decorative and adds no information, use an empty alt="" — never omit the attribute entirely.

3Sizing Images

You can control the display size with width and height attributes (in pixels). Always set both, and keep them in the same ratio as the original image, or your picture will look stretched or squashed.

sized-image.html
<img src="images/mountain.jpg" alt="Snow-capped mountain at sunrise" width="400" height="267">
🔒 sized-image.html
🏔️ mountain.jpg (400×267)
💡 Why Set a Size at All?

Setting width and height reserves the correct space for the image before it fully loads, so the rest of the page doesn't "jump around" while images are downloading. This is a real technique professional sites use.

4Captions with <figure> and <figcaption>

When an image needs a visible caption, wrap it in a <figure> element with a <figcaption> inside. This groups the image and its caption together as one meaningful unit.

figure.html
<figure>
  <img src="images/mountain.jpg" alt="Snow-capped mountain at sunrise" width="400" height="267">
  <figcaption>Mount Kenya at sunrise, taken during our summer trip.</figcaption>
</figure>
📚 Key Vocabulary
src
The attribute pointing to an image file's location
alt text
A written description of an image for accessibility and fallback
Aspect ratio
The proportion between an image's width and height
figure / figcaption
Elements that group an image with its visible caption
🚀 Challenge

Add an image to about-me.html — a photo of yourself, a pet, or something you like — wrapped in a <figure> with a <figcaption>. Write thoughtful alt text, and set a sensible width and height.

✅ Recap

The <img> tag needs src and a meaningful alt attribute. Set width/height in the correct ratio to prevent page jumping. Use <figure> and <figcaption> when an image needs a visible caption. Next lesson: displaying data in tables.
