Code Your World: HTML

A general overview of the course — what it covers, how it's paced, and what learners walk away with. For detailed session plans, see the full course book.

Code Your World: HTML is an online course that introduces learners to the fundamentals of building web pages. Over a series of guided sessions, students move from writing their very first line of code to planning, building, and sharing a finished project of their own — developing a practical, foundational understanding of how websites are put together.

At a Glance

AudienceLearners aged 10–15, no prior experience required
FormatOnline, instructor-led, two sessions per week
DurationRoughly two months
FocusCore web page structure and markup
ToolsA web browser and a basic text editor
OutcomeA finished, original web page

What Learners Will Take Away

By the end of the course, learners should feel comfortable:

  • Explaining how a web page comes together, from code to browser
  • Writing clean, well-organized markup without relying on a page builder
  • Working with everyday elements — text, images, links, lists, and tables
  • Putting together a simple interactive form
  • Following good habits around structure and accessibility
  • Planning, building, and sharing a project of their own

How the Course Is Paced

The course unfolds gradually, with each stage building on the last.

Early on
Getting Oriented
An introduction to how the web works, followed by writing and structuring a first page.
Next
Working with Content
Shaping written content, then organizing it with lists and connecting pages together.
Midway
Media & Interaction
Bringing in images and data, then building simple forms to collect input.
Later
Structure & Polish
Learning how professional pages are organized, and adding richer media.
Closing
Bringing It Together
Applying everything learned to plan, build, and share a personal project.

How Progress Is Checked

Rather than formal tests, learning is reinforced through short, hands-on practice at the end of each session. These build steadily toward a final project in the closing stretch of the course, giving learners a chance to apply everything they've picked up along the way.
