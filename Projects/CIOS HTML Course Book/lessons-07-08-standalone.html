Adding Images

Pictures make pages come alive. Today you'll learn how to add images correctly — including a step every beginner forgets.

🎯 Learning Objectives
  • Insert images using the <img> tag
  • Explain why alt text is required, not optional
  • Size images properly using width and height
  • Add captions with <figure> and <figcaption>

1The <img> Tag

Images use the self-closing <img> tag. It needs a src (source) attribute pointing to the image file — either a file in your own project or a full web address.

image.html
<img src="images/mountain.jpg" alt="Snow-capped mountain at sunrise">

2Alt Text: Not Optional

The alt attribute describes the image in words. It does two important jobs:

  • Screen readers read it aloud, so blind or low-vision visitors know what the image shows
  • If the image fails to load (a typo in the file name, a slow connection), the browser shows the alt text instead — so nobody sees a broken, meaningless icon
⚠️ Write Real Descriptions

Avoid vague alt text like alt="image" or alt="pic1". Describe what's actually shown: alt="A golden retriever catching a frisbee in a park". If an image is purely decorative and adds no information, use an empty alt="" — never omit the attribute entirely.

3Sizing Images

You can control the display size with width and height attributes (in pixels). Always set both, and keep them in the same ratio as the original image, or your picture will look stretched or squashed.

sized-image.html
<img src="images/mountain.jpg" alt="Snow-capped mountain at sunrise" width="400" height="267">
🔒 sized-image.html
🏔️ mountain.jpg (400×267)
💡 Why Set a Size at All?

Setting width and height reserves the correct space for the image before it fully loads, so the rest of the page doesn't "jump around" while images are downloading. This is a real technique professional sites use.

4Captions with <figure> and <figcaption>

When an image needs a visible caption, wrap it in a <figure> element with a <figcaption> inside. This groups the image and its caption together as one meaningful unit.

figure.html
<figure>
  <img src="images/mountain.jpg" alt="Snow-capped mountain at sunrise" width="400" height="267">
  <figcaption>Mount Kenya at sunrise, taken during our summer trip.</figcaption>
</figure>
📚 Key Vocabulary
src
The attribute pointing to an image file's location
alt text
A written description of an image for accessibility and fallback
Aspect ratio
The proportion between an image's width and height
figure / figcaption
Elements that group an image with its visible caption
🚀 Challenge

Add an image to about-me.html — a photo of yourself, a pet, or something you like — wrapped in a <figure> with a <figcaption>. Write thoughtful alt text, and set a sensible width and height.

✅ Recap

The <img> tag needs src and a meaningful alt attribute. Set width/height in the correct ratio to prevent page jumping. Use <figure> and <figcaption> when an image needs a visible caption. Next lesson: displaying data in tables.

Lesson 8 of 16Week 4⏱ 60 minutes

Building Tables

When you need to display rows and columns of information — like a schedule or scoreboard — HTML tables are the tool for the job.

🎯 Learning Objectives
  • Build a table using <table>, <tr>, and <td>
  • Add header cells and group rows with thead/tbody
  • Merge cells using colspan and rowspan
  • Know when a table is (and isn't) the right choice

1Table Basics: Rows and Cells

A table is built from three nested tags: <table> wraps everything, <tr> (table row) creates each row, and <td> (table data) creates each cell within a row.

table-basic.html
<table>
  <tr>
    <td>Alex</td>
    <td>92</td>
  </tr>
  <tr>
    <td>Jamie</td>
    <td>87</td>
  </tr>
</table>

2Header Cells & Structure

Use <th> (table header) instead of <td> for cells that label a column or row — browsers automatically bold and center them, and screen readers announce them as headers. Well-organized tables also group content using <thead> (for header rows) and <tbody> (for the data rows).

table-full.html
<table>
  <thead>
    <tr>
      <th>Student</th>
      <th>Score</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>Alex</td>
      <td>92</td>
    </tr>
    <tr>
      <td>Jamie</td>
      <td>87</td>
    </tr>
  </tbody>
</table>
🔒 table-full.html
StudentScore
Alex92
Jamie87

3Merging Cells: colspan & rowspan

Sometimes one cell needs to stretch across multiple columns or rows. Use colspan to merge across columns, and rowspan to merge across rows.

colspan.html
<tr>
  <th colspan="2">Weekly Schedule</th>
</tr>

That single header cell now spans the width of two normal columns beneath it — perfect for a title row above a schedule.

4When (Not) to Use a Table

⚠️ Tables Are for Data, Not Layout

Years ago, web developers misused tables to arrange whole page layouts (menus, sidebars, columns). That's now considered bad practice — tables should only hold genuine tabular data, like a schedule, scoreboard, or price list. Later, you'll learn CSS, which is the correct tool for page layout.

📚 Key Vocabulary
<table>
The container for an entire table
<tr>
Table row — one horizontal line of cells
<td> / <th>
A regular data cell / a header cell
colspan / rowspan
Attributes that merge a cell across columns or rows
🚀 Challenge

Build schedule.html with a table showing your weekly class or activity schedule: a header row with day names, and one row per time slot. Use <thead>, <tbody>, and at least one merged cell with colspan.

✅ Recap

Tables are built from <table>, <tr>, and <td>/<th>, organized with <thead>/<tbody>. colspan and rowspan merge cells. Tables should hold real data, never be used for page layout. Next lesson: collecting information with forms.
