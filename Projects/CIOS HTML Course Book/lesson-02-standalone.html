Your First Web Page

Every HTML page — from the simplest to the most complex website in the world — starts with the exact same skeleton. Today you'll learn it by heart.

🎯 Learning Objectives
  • Write the doctype declaration and explain what it does
  • Build the required <html>, <head>, and <body> structure
  • Add a page title that appears in the browser tab
  • Save and correctly name an HTML file

1The Anatomy of a Web Page

Every single HTML document follows the same required pattern. Once you memorize this, you'll type it at the top of every page you ever build:

index.html
<!-- This line must always be first -->
<!DOCTYPE html>
<html lang="en">

<head>
  <title>My First Page</title>
</head>

<body>
  <h1>Hello, World!</h1>
  <p>This is my very first complete web page.</p>
</body>

</html>

Let's go through each part, because every piece has an important job:

  • <!DOCTYPE html> — tells the browser "this is a modern HTML5 document." It's not a tag with a closing pair; it's a one-time declaration at the very top.
  • <html> — the root element. Every other tag lives inside this one. The lang="en" part tells the browser (and screen readers) the page is in English.
  • <head> — holds information about the page that isn't shown directly on the page itself (like its title).
  • <body> — holds everything visitors actually see: text, images, buttons, links.

2The <head>: Behind-the-Scenes Info

Think of the <head> like the label on a food package — it's information about the page, not the page's content itself. The most important tag inside it is <title>, which sets the text shown in the browser tab.

🔒 my-first-page.html

Hello, World!

This is my very first complete web page.

Notice that "My First Page" (the title) doesn't appear inside the page body — it only shows in the browser's tab or window title. That's the difference between the <head> and the <body>.

💡 Another Common <head> Tag

You'll also often see <meta charset="UTF-8"> in the head. This simply tells the browser which set of characters to use, so things like emoji, accents (é, ñ), and symbols display correctly. We'll include it in every page from now on.

3Saving Your File Correctly

A few strict rules make sure your file works properly:

  • The file must end in .html — for example, about-me.html
  • Avoid spaces in file names — use hyphens instead: my-page.html, not my page.html
  • Use lowercase letters — profile.html, not Profile.HTML
  • A file named exactly index.html is special: it's the default page a website shows when someone visits a folder or domain without a specific file name
📚 Key Vocabulary
Doctype
The declaration at the top of a file that tells the browser it's HTML5
Root element
The outermost element that contains all others — <html>
Head
Section holding page metadata like the title, not shown directly on the page
Body
Section holding all visible page content
Metadata
Data about the page itself, such as its title or character encoding
File extension
The suffix (like .html) that tells the computer what type of file it is
🚀 Challenge

Build a complete HTML page called about-me.html that includes:

  • A proper doctype, html, head, and body structure
  • A page title (in the <head>) with your name in it
  • One heading and one paragraph (in the <body>) introducing yourself

Open it in your browser and check that your name appears in the browser tab!

✅ Recap

Every HTML page starts with a doctype, then an <html> root element containing a <head> (page info) and a <body> (visible content). The <title> tag sets the browser tab text. Files must be saved with a lowercase, hyphenated .html name. Next lesson, we'll fill the body with properly structured text.
