Lists: Ordered, Unordered & Nested

Lists are everywhere on the web — menus, steps, ingredients, rankings. Today you'll learn all three list types HTML offers.

🎯 Learning Objectives
  • Build unordered (bulleted) lists with <ul> and <li>
  • Build ordered (numbered) lists with <ol> and <li>
  • Nest lists inside other lists
  • Choose the right list type for the content

1Unordered Lists (Bullets)

Use <ul> (unordered list) when the order of items doesn't matter — like a list of favorite foods. Each item inside goes in its own <li> (list item) tag.

bullets.html
<ul>
  <li>Pizza</li>
  <li>Tacos</li>
  <li>Sushi</li>
</ul>
🔒 bullets.html
  • Pizza
  • Tacos
  • Sushi

2Ordered Lists (Numbers)

Use <ol> (ordered list) when order matters — like steps in a recipe. The browser numbers items automatically, so you never type the numbers yourself.

steps.html
<ol>
  <li>Preheat the oven to 200°C</li>
  <li>Mix the dry ingredients</li>
  <li>Bake for 25 minutes</li>
</ol>
🔒 steps.html
  1. Preheat the oven to 200°C
  2. Mix the dry ingredients
  3. Bake for 25 minutes

You can change where numbering starts with the start attribute (e.g. <ol start="4">), or switch the numbering style with type (e.g. type="A" for A, B, C or type="i" for i, ii, iii).

3Nesting Lists

You can put a whole list inside a single <li> to create sub-items — this is called nesting. It's perfect for things like packing lists with categories.

packing.html
<ul>
  <li>Clothes
    <ul>
      <li>T-shirts</li>
      <li>Jacket</li>
    </ul>
  </li>
  <li>Toiletries</li>
</ul>
🔒 packing.html
  • Clothes
    • T-shirts
    • Jacket
  • Toiletries
⚠️ Watch the Nesting

The nested <ul> must go inside the <li> of its parent item, not after it closes. Getting this indentation right in your editor makes mistakes much easier to spot.

4Bonus: Description Lists

A third, less common list type is the description list, used for term/definition pairs like a glossary: <dl> wraps it, <dt> holds the term, and <dd> holds its description.

glossary.html
<dl>
  <dt>HTML</dt>
  <dd>The language used to structure web pages</dd>
</dl>
🔒 glossary.html
HTML
The language used to structure web pages
📚 Key Vocabulary
Unordered list
A bulleted list where order doesn't matter — <ul>
Ordered list
A numbered list where order matters — <ol>
List item
A single entry in a list — <li>
Nesting
Placing one list (or element) inside another
Description list
A term/definition list using <dl>, <dt>, <dd>
🚀 Challenge

Create my-week.html. Include an <ol> listing the steps of your morning routine (at least 4 steps), and a <ul> of your favorite subjects at school, with at least one item containing a nested <ul> of reasons why you like it.

✅ Recap

Use <ul> for unordered content, <ol> for ordered/step-based content, and nest lists by placing a new list inside an <li>. Description lists (<dl>) handle term/definition pairs. Next lesson: connecting pages with links.

Lesson 6 of 16Week 3⏱ 60 minutes

Links & Navigating the Web

Links are what turn separate pages into a "web." Today you'll connect your pages to each other — and to the rest of the internet.

🎯 Learning Objectives
  • Create links using the <a> tag and href attribute
  • Explain the difference between absolute and relative links
  • Open links safely in a new browser tab
  • Build jump links that scroll to a section within the same page

1The Anchor Tag

Links are created with the anchor tag, <a>. The destination goes in the href attribute (short for "hypertext reference"), and the clickable text goes between the opening and closing tags.

links.html
<a href="https://www.wikipedia.org">Visit Wikipedia</a>
🔒 links.html
Visit Wikipedia

2Absolute vs. Relative Links

There are two kinds of link destinations:

  • Absolute links — the full web address, including https://, used for linking to other websites.
  • Relative links — just the file name or path, used for linking between pages within your own project. These are shorter and keep working even if your whole site moves to a new address.
nav-example.html
<!-- Absolute: points to an entirely different site -->
<a href="https://www.nasa.gov">NASA</a>

<!-- Relative: points to a file in the same project -->
<a href="about-me.html">About Me</a>
<a href="hobby.html">My Hobby</a>
Link typeLooks likeUse it for
Absolutehttps://www.nasa.govOther people's websites
Relative (same folder)hobby.htmlAnother page of your own site
Relative (sub-folder)pages/hobby.htmlA page inside a folder
Relative (up a folder)../index.htmlGoing back out of a folder

3Opening Links in a New Tab

Add target="_blank" to open a link in a new tab instead of navigating away from your page — useful for external links so visitors don't lose their place. When you do this, it's good practice to also add rel="noopener", which is a small security measure that stops the new tab from being able to control your original page.

new-tab.html
<a href="https://www.nasa.gov" target="_blank" rel="noopener">NASA (opens in new tab)</a>
💡 Write Link Text That Means Something

Avoid links that just say "click here." Screen reader users often skim a list of every link on a page, and a page full of "click here" tells them nothing. Write the destination into the text itself — "Read the NASA mission page" beats "click here" every time.

4Jump Links Within a Page

You can also link to a specific spot on the same page. Give the target element an id, then link to it using a # followed by that id.

jump-link.html
<a href="#hobbies-section">Jump to Hobbies</a>

<!-- further down the page -->
<h2 id="hobbies-section">My Hobbies</h2>

This is exactly how the "back to top" links and table-of-contents links you see on long web pages and Wikipedia articles work.

Hyperlink

href
The attribute on <a> that sets the link's destination
Absolute URL
A full web address including https://, for external sites
Relative URL
A short path to a file within your own project
target="_blank"

🚀 Challenge

Add a small navigation menu of links to the top of about-me.html, hobby.html, and my-week.html so you can click between all three pages you've built so far. On one page, add an id to a heading further down and create a jump link to it.

✅ Recap

The <a href> tag creates links — absolute URLs for other sites, relative URLs for your own pages. target="_blank" opens links in a new tab, and id + # creates jump links within a page. Next lesson: adding images.
