Part A — Concept Recap ≈ 10 min

Answer each in one or two sentences, in your own words.

  1. What job does each of HTML, CSS, and JavaScript do in a web page? (Session 1)
    Show answer

    HTML = structure (the elements on the page). CSS = style (colours, spacing, layout). JavaScript = behaviour (what moves, responds, and changes). Mental picture: HTML is the noun, CSS the adjective, JavaScript the verb.

  2. What is the <canvas> element, and which two values must always be set as HTML attributes rather than only in CSS? (Session 2)
    Show answer

    Canvas is a blank rectangle JavaScript can draw on. Its width and height must be set as attributes — setting size only via CSS stretches and blurs the drawing.

  3. On a canvas, which direction does y grow — and why does this trip up beginners? (Session 2)
    Show answer

    y grows downward (0 is the top-left corner), the opposite of school-maths graphs where y grows upward. Beginners expect increasing y to move things up, but it moves them down.

  4. What's the difference between padding and margin? (Session 3)
    Show answer

    Padding is space inside an element, between its content and its own border. Margin is space outside an element, pushing other elements away.

  5. Name the three ways to add CSS to a page, and which one this course uses by default while learning. (Session 3)
    Show answer

    Inline (style attribute), internal (a <style> block in <head>), and external (a linked .css file). The course defaults to internal <style> blocks early on for simplicity.

  6. When should you use let versus const in JavaScript? (Session 4)
    Show answer

    Use const by default for values that shouldn't change; switch to let only when the value needs to change later (like a score or position).

  7. What does += do? Write one example. (Session 4)
    Show answer

    It adds to the existing value and reassigns it — shorthand for x = x + value. Example: score += 10 adds 10 to score.

  8. What does "2" + "2" evaluate to in JavaScript, and why is it different from 2 + 2? (Session 4)
    Show answer

    "2" + "2" gives "22" because both are strings, so + joins (concatenates) text instead of adding numbers. 2 + 2 gives 4 because both are numbers.

Part B — Read the Code ≈ 15 min

For each snippet, say what happens when it runs — or spot the mistake.

1. What's wrong with this HTML?

<body>
  <h1>My Game
  <p>Get ready to play.</p>
</body>
Show answer

The <h1> tag is never closed with </h1>. Tags come in pairs — forgetting the closing tag is one of the most common beginner mistakes.

2. Where on a 300×200 canvas will this rectangle appear — near which corner?

ctx.fillStyle = "tomato";
ctx.fillRect(200, 10, 60, 40);
Show answer

Near the top-right. x=200 is far to the right (out of 300 wide), y=10 is near the top (y grows downward), sized 60 wide × 40 tall.

3. Given this CSS, which element(s) turn blue?

#score { color: blue; }
.label { color: green; }
<p id="score" class="label">Score: 0</p>
<p class="label">Lives: 3</p>
Show answer

Only the first paragraph turns blue — an id selector (#score) targets just that one element. The second paragraph has no id match, so it stays green from the .label class rule.

4. What does each line print to the console?

let lives = 3;
console.log("Lives: " + lives);
console.log(lives + 1);
console.log("Lives: " + lives + 1);
Show answer

"Lives: 3" (number joined to text) — then 4 (number maths) — then "Lives: 31" (once a string is involved, + reads left to right and joins each following value as text: "Lives: 3" + 1 = "Lives: 31").

Part C — Hands-On Build ≈ 25 min

Open a new session-checkpoint folder in VS Code and build a single index.html that does the following. Use Live Server to check your work as you go.

Step 1 — Frame (Sessions 1 & 3): Build a page with a dark background, a heading with your game's working title, and a <canvas> sized 360×240 centred on the page using flexbox.
Step 2 — Drawing (Session 2): On the canvas, draw at least two different shapes (rectangle, circle, or both) in two different colours, plus one piece of text using fillText.
Step 3 — Variables (Session 4): Add a let score = 0; variable and a button below the canvas labelled +15 points. Each click should add 15 to score and redraw the canvas so the text shows "Score: " + score.
Show one possible solution 
<!DOCTYPE html>
<html>
<head>
<style>
  body { margin:0; min-height:100vh; display:flex; flex-direction:column;
    align-items:center; justify-content:center; gap:14px;
    background:#0d1024; color:#e9ecff; font-family:system-ui,sans-serif; }
  #game { background:#0b0e24; border:3px solid #6c8cff; border-radius:12px; }
  button { padding:10px 18px; border:none; border-radius:8px;
    background:#6c8cff; color:#fff; font-size:15px; cursor:pointer; }
</style>
</head>
<body>
  <h1>Star Catcher</h1>
  <canvas id="game" width="360" height="240"></canvas>
  <button id="add">+15 points</button>
  <script>
    const ctx = document.getElementById("game").getContext("2d");
    let score = 0;

    function draw() {
      ctx.fillStyle = "#0b0e24";
      ctx.fillRect(0, 0, 360, 240);
      ctx.fillStyle = "tomato";
      ctx.fillRect(30, 30, 80, 60);
      ctx.fillStyle = "dodgerblue";
      ctx.beginPath();
      ctx.arc(250, 60, 40, 0, Math.PI * 2);
      ctx.fill();
      ctx.fillStyle = "#e9ecff";
      ctx.font = "22px sans-serif";
      ctx.fillText("Score: " + score, 100, 180);
    }

    document.getElementById("add").onclick = function () {
      score += 15;
      draw();
    };
    draw();
  </script>
</body>
</html>
