A Note to Parents

Where curiosity becomes real skill

Thank you for considering Game Development Pro for your child. This program was designed around a simple belief: young people learn best when they are building something they are proud of. Instead of abstract exercises, every lesson moves your child closer to a real, playable game they can share with friends and family.

Over three months, students learn the same three technologies that power the entire web — HTML, CSS and JavaScript — and use them to create classics like Pong, Snake and Breakout, finishing with their own platform game. Along the way they pick up something far more valuable than any single language: the ability to break a big problem into small steps, to stay calm when something doesn’t work, and to keep going until it does.

The course assumes no prior experience whatsoever. We begin by helping each student install professional tools, and every session is carefully paced so that it builds gently on the one before. By the final week, your child will have published a real game to the internet with a link they can proudly send to you.

— The Team at Code Illustrated Online School

How the Program Works

A calm, predictable rhythm designed so beginners never feel left behind. Every session is a direct follow-up to the last.

Schedule & Format

  • 12 weeks in total, organised into three monthly stages.
  • Two live 1-hour sessions each week (24 sessions).
  • Each session blends clear teaching with hands-on building.
  • Short, optional practice challenges reinforce each lesson.
  • Written notes and runnable examples for easy review or catch-up.

What You’ll Need

  • A computer — Windows, Mac or Linux all work.
  • A reliable internet connection.
  • A free code editor & web browser — we install these together in Session 1.
  • No paid software and no prior coding experience required.

The Three Stages

  • Month 1 — Foundations: tools, the web, and the building blocks of code.
  • Month 2 — Core Mechanics: movement, controls, collisions & first games.
  • Month 3 — Real Projects: bigger games, polish & publishing.

Our Teaching Approach

  • Learn by building — a real result in every single session.
  • Concepts explained in plain language, then practised immediately.
  • Mistakes treated as part of learning, never something to fear.
  • Steady pacing — each idea rests on the one before it.

A typical session

A short recap of last time → a new concept explained simply → guided building on screen → a small challenge to try → a clear summary of what was learned and what comes next. Students always leave with something that works.

Questions Parents Often Ask

Does my child need any coding experience?

None at all. The course is built for complete beginners and starts by installing the tools together. Every new term is explained in plain language the first time it appears.

What equipment and software are required?

Any computer (Windows, Mac or Linux) with an internet connection. All software used is completely free, and we help install it during the first session.

Is the content age-appropriate and safe?

Yes. Lessons use school-safe, industry-standard tools, and any work published online uses free, reputable hosting. Screen time is purposeful and creative.

What if my child misses a session?

Every session comes with written notes and runnable examples, so a missed lesson is easy to catch up on before the next one.

Will this help with school or a future career?

Absolutely. Students gain genuine programming foundations, computational thinking, and a portfolio — valuable for school computing, further study, and beyond.

What does my child finish with?

Four complete games, one published live on the internet, written notes for everything covered, and the confidence and skills to keep building independently.
