DOCKING BAY

Flying is easy. Parking is hard. Bring the shuttle to rest completely inside the docking bay.

Session 10≈ 20 minutes Held keys & clampingIn-class challenge

🛰️ The situation

Every game with a controller has two kinds of movement: the fast one for getting around, and the slow one for being precise. Sniper scopes, crouch-walking, parking a vehicle. Today you build both, on one shuttle.

The drawing is already written for you. What's missing is the entire input system and the docking test.

Your job: fly the shuttle with the arrow keys, hold Shift to slow down for precision, and light the bay up green when the shuttle is fully inside it.

Requirements

  1. Arrow keys move the shuttle in all four directions, smoothly, with no stutter — and diagonals must work.
  2. The shuttle can never leave the canvas.
  3. While Shift is held, it moves at PRECISION_SPEED instead of NORMAL_SPEED.
  4. isDocked() returns true only when the whole shuttle is inside the bay. One corner poking out is not docked.
🔑 "Fully inside" is not the same as "touching"
In Session 12 you'll learn the test for two rectangles overlapping. This is a different question: is one rectangle completely within another? Draw both rectangles on paper, label the four edges of each, and write down the four things that must all be true at once. Then join them with AND.
⚠️ Two reminders from last session
Don't move the shuttle inside the keydown handler — you know what that does to the feel. And key names are spelled exactly: if a key does nothing, print event.key to the console and read what the browser actually calls it.

Done when you can fly diagonally, hold Shift to creep, park the shuttle fully inside the bay so it turns green, then nudge it one pixel out and watch the green switch off.

🚀 If you finish early

  1. Score it. When the shuttle docks, move the bay to a random new spot and add 1 to a score shown at the top. Keep the shuttle where it is — no teleporting the player.
  2. Ramp it up. Make the bay a little smaller with each successful dock. How small before it becomes impossible? Is that a bug or a difficulty curve?
  3. The stuck key. Hold an arrow, click outside the canvas while still holding, then release. Watch the shuttle keep flying. Then fix it in three lines — you saw the fix in Session 10.
🤔 Think about this one before you leave
Holding Shift is read from your keys object, exactly like an arrow. So what's actually the difference between a "movement key" and a "modifier key"? Is there any difference in the code at all?
